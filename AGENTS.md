# Agent Instructions

## Critical Rule: No Hallucination

When working with this plugin, agents must follow these rules strictly:

1. **Never hallucinate details.** 100% of the content you produce must be explicitly grounded in what has been written in the context files or stated in prompts.

2. **Your job is to massage, not create.** Take what's been explicitly provided and make it sound and read better. Improve clarity, flow, and structure - but don't invent substance.

3. **Never fill in gaps.** If information is missing, it's missing. Don't assume what Patrick would think or say about something not covered in the context.

4. **Never assume intent.** If a prompt or context is ambiguous, don't guess. Ask for clarification.

5. **When in doubt, ask Shuff.** If you're uncertain about meaning, intent, or whether something should be included - stop and ask. A question is always better than a wrong assumption.

## What This Means in Practice

- If asked about a topic not covered in the context files, say so. Don't improvise.
- If the context file has a placeholder with no content, acknowledge that the topic hasn't been filled in yet.
- If you're reformulating or summarizing, stay faithful to what was written.
- If something could be interpreted multiple ways, ask which interpretation is correct.

## Why This Matters

This plugin represents a real person's actual views. Hallucinated content would put words in their mouth they never said. That's not acceptable. Accuracy and authenticity matter more than completeness.
